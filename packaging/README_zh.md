# 施工照片標記與報告產生工具

給完全沒寫過程式的人看的使用說明。跟著步驟做就可以了。

（這份文件講的是完整功能細節；如果只想快速上手，同一個資料夾裡的「說明.txt」有更精簡的版本。）

---

## 這個工具在做什麼

1. 照片來源有兩種：把照片放進電腦的 `incoming`（等候區）資料夾，或是直接用手機在工地現場拍照上傳
2. 打開控制台，啟動網頁畫面，一張一張裁切、選分類、選說明文字，按儲存
3. 全部確認沒問題後，按一下「完成本次作業」，程式會自動蓋上日期浮水印、把照片搬進 `sorted` 資料夾整理好，並記錄在 `manifest.csv`
4. 在控制台或網頁畫面按一下「產生報告」，自動產生 Word 報告，排版跟原本的範例檔一樣

---

## 第一次使用：安裝（只需要做一次）

1. 如果拿到的是壓縮檔，先解壓縮
2. 雙擊「安裝.bat」
3. 如果跳出「偵測不到 Python」，照畫面指示到 https://www.python.org/downloads/ 安裝
   （安裝畫面最下面記得勾選 **"Add python.exe to PATH"**），裝完後重新雙擊「安裝.bat」
4. 按 Enter 使用預設安裝位置，或自己輸入想安裝的資料夾路徑
5. 等它跑完（第一次安裝套件可能要一兩分鐘），出現「安裝完成！」就結束了

安裝完成後，打開你剛剛安裝的那個資料夾，之後每天都在裡面操作。之後如果拿到新版本要更新，重新雙擊「安裝.bat」、安裝到同一個資料夾即可——你的照片、`manifest.csv` 等資料不會被覆蓋或刪除。

## 每天的使用流程

### 步驟 1：打開控制台

雙擊資料夾裡的「工地照片系統.bat」，會打開一個控制台視窗，之後所有操作都在這個視窗裡完成，不用再記其他檔案或指令。控制台由上而下有五個方框：

- **工地（手機拍照連結）**：一個工地一列，顯示工地名稱、目前狀態、手機要連的網址。先點選要操作的那一列，再按下面的按鈕：「啟動」／「停止」（手機版伺服器）、「複製網址」、「改名」、「＋ 新增工地」、「移除工地」
- **辦公室版（標記、產生報告）**：同樣一個工地一列。點選工地後按「開啟」，瀏覽器就會打開那個工地的標記畫面；按「停止」關閉
- **工程設定**：工程名稱／承攬廠商／報告標題，改完按「儲存設定」。這一份是**跟著上面選到的工地走**的，每個工地可以不一樣
- **產生報告**：選工地、選施工日期，按「📄 產生報告」（日期沒出現的話按「重新整理」）
- **訊息記錄**：執行狀況、錯誤訊息都會顯示在這裡

只有一個工地時，清單裡就只有一列（預設叫「主要工地」），照樣點一下再按按鈕即可。

關閉這個控制台視窗**不會**停止已經啟動的伺服器；下次要停止的話，重新打開「工地照片系統.bat」再按「停止」即可。

### 步驟 2（可選）：手機在工地現場拍照

1. 在控制台最上面的「工地」清單點選要用的工地，按「啟動」
2. 第一次執行會需要登入 Tailscale（用 Google 或 Microsoft 帳號都可以，免費）：
   - 沒裝過的話控制台會自動幫你打開下載頁面，裝完後重新按一次「啟動」
   - 跳出瀏覽器要求登入，登入完成回到控制台即可，會自動繼續
3. 那一列的「手機網址」欄會出現一串網址（例如 `https://電腦名稱.xxxxx.ts.net`），按下面的「複製網址」，傳到手機上（LINE、訊息都可以）
4. 手機用瀏覽器打開這個網址，就可以開始拍照

手機畫面的操作方式：

- 按大大的「📷 拍照」按鈕，會直接開啟手機原生相機（不是網頁模擬鏡頭，畫質正常）
- 畫面上方有連線狀態小標籤（🟢已連線／🔴連線中斷），工地訊號不穩時可以留意這個，連線中斷也不會遺失已經拍好還沒存檔的照片
- 拍完照片會自動置中裁切成報告版面比例（不能手動拖曳調整，回辦公室用辦公室版還可以重新調整）；如果照片是側躺的，按「🔄 旋轉90度」修正
- 選分類、材料別/標線種類；按「▶ 📋 分類清單」可以展開看今天這個分類底下，哪些常用說明已經拍過（✅）、哪些還沒（⬜），方便確認有沒有漏拍
- 選擇「照片說明」，清單裡有常用的可以直接點，也可以選「➕ 自行輸入新的說明...」自己打字
- 按「✅ 儲存，拍下一張」

手機拍的照片會先存進共用的暫存區，回辦公室啟動「辦公室版」時，會直接出現在「📦 本次工作階段」清單裡，跟電腦匯入的照片一起檢查、確認、產生報告。

之後每天只要按「啟動」就好，不會再跳出登入畫面。用完按「停止」關閉（工地手機不需要再連線時記得按停止，比較省電/安全）。

### 步驟 3：電腦標記／確認照片（辦公室版）

在控制台「辦公室版」那個方框點選要開的工地，按「開啟」，瀏覽器會自動打開那個工地的網頁畫面（預設工地是 `http://localhost:8501`，之後新增的工地各自有自己的埠號，從 8511 開始往上排，清單的「網址」欄會直接顯示）。

畫面左邊側邊欄最上面一行就是今天的狀況：「待標記 N ・ 待確認 N ・ 已完成 N」，底下依序是「🗂️ 整理 incoming」「📦 本次工作階段」「🔍 施工總覽」「📄 產生報告」四個區塊。

如果照片是用電腦匯入的（不是手機拍的），先把今天的照片放進 `incoming` 資料夾——可以手動複製貼上，也可以把 Google Drive / OneDrive 的雲端同步資料夾路徑直接設成這個 `incoming` 資料夾，手機拍照上傳雲端後電腦這邊會自動出現。

**支援的檔案格式**：`.jpg`、`.jpeg`、`.png`、`.heic`（iPhone 預設的拍照格式）。不用先自己轉檔，HEIC 可以直接讀，按「完成本次作業」歸檔時會自動存成 `.jpg` 進 `sorted`，這樣 Word 和 Windows 內建的相片檢視器都打得開。（HEIC 解碼比較慢，照片量大的時候「整理 incoming」的縮圖畫面第一次跑可能要等一下才會全部出現，這是正常的，不是當掉。）

如果 `incoming` 裡有很多不需要標記的照片（例如不小心同步進來的無關照片），可以先按左側「🗂️ 整理 incoming」底下的「挑出要忽略的照片」，勾選後搬到 `ignored` 資料夾（不會刪除，之後想要還可以自己搬回 `incoming`）。

每張照片有**兩個日期欄位**，意義不一樣：

- **📅 拍照日期**：這張照片實際是哪一天拍的。這個日期會直接**蓋印在照片右下角**，等到按「完成本次作業」正式歸檔後就已經燒錄好了，之後無法移除。
- **🏗️ 施工日期**：這張照片要歸進報告裡的哪一天，決定資料夾跟報告的分類。預設會跟拍照日期一樣，但可以自己改（例如工程是 7/1 做的，但補拍到 7/2 才拍，施工日期設 7/1、拍照日期照實填即可）。

標記步驟：

1. **✂️ 裁切照片**：畫面左邊會顯示照片，比例已經鎖定成報告版面的照片格，用滑鼠拖曳調整取景範圍
2. 確認/修改「拍照日期」——自動從照片本身讀取拍攝日期並帶入，偵測錯誤（例如相機時間設定錯誤）可以直接改
3. 確認/修改「施工日期」——預設跟拍照日期一樣
4. 選擇「分類」，如果分類底下有材料別（DGAC/OGAC/PAC）或標線種類選項也一併選好
5. 按「▶ 📋 分類清單」核對今天這個分類還有哪些常用說明沒拍到
6. 選擇「照片說明」，或選「➕自行輸入新的說明...」自己打字；清單裡打錯字或不再需要的項目可以按旁邊的「✕」刪掉
7. 按「儲存並下一張」

**注意：按下「儲存並下一張」之後，照片還沒有真的蓋上浮水印、搬進 `sorted` 資料夾**——它只是先記錄進左側「📦 本次工作階段」清單。在正式送出之前，隨時可以在側邊欄「回去修改已標記的照片」選單裡選到任何一張（不管是電腦匯入的還是手機拍的），回頭調整分類、說明、裁切範圍或日期，改完按「💾 更新這張」。

全部確認沒問題後，按側邊欄的「✅ 完成本次作業（N 張）」，才會一次把裁切和日期浮水印真正套用到全部照片、正式歸檔進 `sorted` 資料夾並寫進 `manifest.csv`。

**關於截圖、LINE 下載的圖片**：這類圖片通常沒有拍攝時間資訊，畫面上會出現黃色提醒（⚠️），下面顯示的只是用檔案儲存時間猜測的日期，請務必手動輸入正確的拍照日期。

標記完後，可以直接關掉瀏覽器分頁，回到控制台按「辦公室版」的「停止」。

### 步驟 3b（建議）：產生報告前先看一次「施工總覽」

在側邊欄「🔍 施工總覽」選施工日期，按「🔍 檢查本日照片」，會一次列出當天每個分類拍了什麼、哪些還沒拍、哪些可能拍重複了。有重複時按鈕會變紅色並直接寫出幾項，例如「🔍 檢查本日照片（1 項重複）」。

重複的判定是「同一個施工日期、同一個分類、說明文字一模一樣有 2 張以上」：

- 「AC刨除厚度5cm」跟「AC刨除厚度7cm」是兩個不同的量測點，**不算**重複；材料別不同（DGAC／PAC）也一樣不算
- 交維照片這種規定要拍很多張的分類，**完全不檢查**重複
- 如果整個分類幾乎每一項都剛好兩張，會判斷成「同一天做了兩個路段」，只在分類下面提醒一句，不會逐項標紅

發現重複時，面板會把那幾張並排顯示（每張都是一樣大小的預覽方框，不會因為直式橫式而大小不一），直接看圖決定要留哪一張，按照片下面的「🗑️ 移出報告」把多的那張移走。**不會刪除檔案**，只是搬到 `ignored` 資料夾，判斷錯了還救得回來。

這只是提醒，不會擋住產生報告。

### 步驟 4：產生 Word 報告

兩種方式都可以：

- **控制台**：「產生報告」那排選工地、選日期，按「📄 產生報告」，完成後會問要不要打開報告所在的資料夾
- **辦公室版網頁畫面**：左側邊欄「📄 產生報告」選日期，按「📄 產生報告」，完成後按「⬇️ 下載報告」直接下載

兩種方式產生的報告完全一樣，選一種順手的就好。報告會出現在 `output` 資料夾。

## 同一天有兩個工地在施工

同一台電腦可以同時服務好幾個工地，每個工地有自己的手機網址、自己的照片、自己的報告。

在控制台最上面的「工地」方框按「＋ 新增工地」，輸入工地名稱（例如「光復路段」）就會建好，並產生一組專屬的手機網址。把不同的網址發給不同工地的人即可。

- 每個工地的照片、`manifest.csv`、報告各自分開放在 `sites\<代號>\` 底下，互不影響
- **工程名稱／承攬廠商／報告標題每個工地各自一份**，在控制台選好工地再改「工程設定」即可；沒有另外設定的工地，沿用 `config.json` 裡的值
- **分類與常用說明清單則是所有工地共用**一份，在 A 工地新增的說明，B 工地的手機馬上也看得到——那是「公司怎麼拍檢查照片」的共同規則，不該跟著工地分家
- 報告檔名會帶上工地名稱（例如 `查驗照片_2026-07-23_光復路段.docx`）

**為什麼一定要分開**：報告是以「施工日期」當索引的。兩個工地的照片如果混在一起，同一天會被合併成一份報告，而且交維照片的最低張數檢查會把兩邊加起來算——各拍 3 張會被當成 6 張通過，報告表面上完全看不出異常。

### 工地名稱與手機標題

手機畫面標題會顯示工地名稱（例如「📷 現場拍照－光復路段」），避免有人拿著錯的連結拍照。剛安裝好時預設工地叫「主要工地」，那只是個佔位名稱，**不會**顯示在手機上；用「改名」改成真正的路段名稱之後才會出現。

「改名」只改顯示的名稱，**手機網址不會變**，工人已經存的書籤照樣能用。改完之後要按「停止」再「啟動」，手機標題才會更新。

### 移除工地

「移除工地」會停掉伺服器、收回手機網址、從清單移除，並且**把那個工地的資料夾一起刪掉**（照片、報告全部）。刪除是**移到 Windows 的「資源回收筒」**，不是直接抹掉，按錯還可以還原；如果那個工地裡面有照片或報告，確認視窗會直接告訴你有幾張照片、幾份報告。

「主要工地」不能移除：它的資料夾就是程式本身所在的資料夾。想換名字請用「改名」。

## 想修改工程名稱／廠商，或新增/修改分類、常用說明文字？

- **工程名稱、承攬廠商、報告標題**：控制台「工程設定」欄位直接改，按「儲存設定」即可
- **分類與常用說明清單**：打開 `config.json`（用記事本開就好，是純文字設定檔），可以直接修改：
  - `"categories"`：每個分類的名稱，以及底下常用的照片說明清單

  修改完存檔，重新啟動辦公室版就會套用，完全不用碰程式碼。標記畫面裡按分類/說明旁邊的「✕」也可以直接刪除項目，效果跟手動編輯這個檔案一樣。

`captions` 清單裡除了純文字，也可以放進階設定（例如「鋪築施工照片」「標線標記照片」現在就是這樣寫的）：

- 分類加上 `"material_options": ["DGAC", "OGAC", "PAC"]` → 標記畫面選到這個分類時會多跳出「材料別」下拉選單，說明文字裡的 `{material}` 會自動換成選到的材料，且材料代號在標記畫面預覽跟 Word 報告裡都會變紅字
- 分類加上 `"type_options": [...]` → 效果同上，但用來做像「熱聚酯標線/臨時標線」這種二選一，且不會標紅
- 說明文字寫成 `{"template": "AC刨除厚度{value}cm", "fill_in": true, "label": "AC刨除厚度"}` → 選到這條時，畫面會多跳出一個空格讓你填數字，存檔時自動接上去
- 說明文字寫成 `{"template": "熱聚酯標線溫度", "only_type": "熱聚酯標線"}` → 只有在「標線種類」選到指定的值時，這條說明才會出現在清單裡
- 分類加上 `"min_required": 6` → 標記畫面會顯示「本日已標記幾張／還差幾張」，Word 報告裡張數不足時該分類標題下也會出現紅字警告

這些進階設定看不懂也沒關係，直接照抄現有分類的寫法修改文字內容即可；純文字的說明（沒有 `{}`）完全不受影響。

## 常見問題

**Q: 雙擊「安裝.bat」出現「偵測不到 Python」？**
到 https://www.python.org/downloads/ 安裝，記得勾選 "Add python.exe to PATH"，裝完後重新雙擊「安裝.bat」。

**Q: 手機打開網址顯示「無法連上網站」？**
回控制台看那個工地在「工地」清單裡的「狀態」欄，如果顯示「未啟動」，點選那一列按一次「啟動」重新開啟即可。

**Q: 這台電腦可以關機嗎？**
想讓工地手機連進來拍照的話不行，控制台本身可以關，但那個工地的手機版伺服器要保持啟動狀態。純粹在辦公室標記、產生報告的話，按「辦公室版」的「停止」後就可以關機。

**Q: 照片上蓋印的日期浮水印可以移除或修改嗎？**
不行，浮水印是在按「完成本次作業」的時候才畫在照片圖檔上的，套用之後就無法移除或修改。請務必在按下「完成本次作業」之前，用側邊欄「回去修改已標記的照片」確認每一張的「拍照日期」欄位是正確的。

**Q: 分類或說明選錯了，存檔後才發現怎麼辦？**
如果還沒按「完成本次作業」：在側邊欄「📦 本次工作階段」的選單裡選到那張照片，會出現修改畫面，改完按「💾 更新這張」即可。
如果已經按過「完成本次作業」：說明文字要去 `manifest.csv` 裡改那一列的 `caption` 欄位（用 Excel 打開修改存檔即可）。如果連分類都選錯了，除了改 `manifest.csv` 的 `category` 欄位，還要把 `sorted` 裡對應的照片檔案手動搬到正確分類的資料夾。

**Q: 想把某張照片從報告中移除？**
把 `sorted` 裡對應的照片檔案刪掉，並在 `manifest.csv` 裡刪掉那一列（用 Excel 打開編輯），存檔後重新產生報告。

**Q: 想同時處理好幾天的照片？**
沒問題，`incoming` 資料夾可以混著放不同天拍的照片。標記每一張時，把「施工日期」設成這張照片要歸進報告裡的哪一天即可。之後產生報告時，分別針對每個日期各產生一次。

## 資料夾結構說明

```
工地照片系統/（安裝完成後的資料夾）
├── incoming/            ← 電腦匯入、待標記的新照片放這裡
├── staging/             ← 「本次工作階段」還沒按「完成本次作業」的照片暫存在這裡（程式自動管理）
├── ignored/             ← 用「整理 incoming」標記成不需要的照片會搬到這裡（不會刪除）
├── sorted/              ← 已完成歸檔、自動整理好的照片（按 日期/分類 分資料夾）
├── output/              ← 產生好的 Word 報告
├── sites/               ← 第二個以後的工地各自的資料夾（照片、manifest、報告都在裡面）
├── venv/                ← 程式內部在用的 Python 執行環境（不用管，也不要手動刪改）
├── manifest.csv         ← 所有已完成歸檔照片的紀錄清單（程式自動產生與維護）
├── session_pending.csv  ← 「本次工作階段」尚未完成歸檔的照片清單（程式自動產生與維護）
├── config.json          ← 分類與常用說明設定（可自行編輯，所有工地共用）
├── site_config.json     ← 這個工地自己的工程名稱/承攬廠商/報告標題（控制台「儲存設定」會維護）
├── sites.json           ← 工地清單（控制台的「＋ 新增工地」會自動維護）
├── 工地照片系統.bat       ← 雙擊開啟控制台（日常操作都從這裡開始）
├── 說明.txt              ← 精簡版快速上手說明
├── control_panel.py     ← 控制台程式本身
├── app.py                ← 辦公室版標記工具
├── mobile_app.py         ← 手機版拍照工具
├── generate_report.py    ← 報告產生器
└── utils.py               ← 共用工具程式（不需要修改）
```
